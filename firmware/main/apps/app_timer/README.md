# Presentation Timer (タイマーアプリ)

Stack-chan 上で動作するプレゼンテーション向けタイマーアプリケーションです。  
設定時間に対する残り時間の割合に応じて、円弧ゲージの色変化、ベル（チャイム）音、およびサーボによる愛らしいモーション（首振り・キョロキョロ・お辞儀）で進行状況を知らせます。

---

## 主な機能

### 1. タイマー設定画面
- **時間設定**: `1分 〜 99分`（初期値: 5分）
  - `-10`, `-1`, `+1`, `+10` ボタンで直感的に調整可能
- **操作**:
  - `START`: タイマーを開始し、実行画面へ遷移
  - 左上の戻るボタン（`←`）または下部ホームインジケーター: ホーム（ランチャー）へ戻る

### 2. タイマー実行画面
- **円弧ゲージ & 残り時間バッジ**:
  - 12時方向から時計回りに減っていく円弧ゲージ（直径 176px）
  - 右上に `MM:SS` 形式の控えめなデジタル表示
- **スタックちゃんの表情アニメーション**:
  - ゲージの中央にスタックちゃんの顔（目・口）を表示
  - 実行中は3〜6秒ごとにランダムでまばたきを実行
- **操作ボタン**:
  - `CANCEL`（左上）: タイマーを中断して設定画面に戻る
  - `PAUSE` / `RESUME`（左下）: 一時停止および再開
  - `RESET`（終了時・左下）: 設定画面へ戻る

---

## 進行状況に応じたアラート & モーション

タイマー進行度（残り時間の割合）に応じて、視覚・聴覚・動作のフィードバックを行います。

| 残り割合 | ゲージ色 | チャイム音 | サーボモーション / 表情 | 説明 |
| :--- | :--- | :--- | :--- | :--- |
| **100%〜51%** | 🟢 緑 (`#2ECC71`) | なし | まばたき | 通常進行状態 |
| **50% 到達** | 🟢 緑 (`#2ECC71`) | なし | **1回首振り** | 半分経過を静かに通知（片側に首を傾けてから正面に戻る） |
| **30% 到達** | 🟡 黄 (`#F1C40F`) | **1鈴**（高音チャイム） | **1回首振り** | そろそろ終盤であることを音と動作で通知 |
| **10% 到達** | 🔴 赤 (`#E74C3C`) | **2鈴**（2連チャイム） | **キョロキョロ** | 締めくくりへの注意喚起。時間切れまで数秒おきに見渡す動作 |
| **0%（終了）** | 🔴 赤 (`#E74C3C`) | **3鈴**（3連チャイム） | **正面待機** | 時間切れを通知し、ステータスに「TIME UP!」と表示 |

## 終了後のお礼インタラクション（お辞儀）

プレゼンテーション終了後、発表のお礼動作をインタラクティブに行えます。

- **トリガー**:
  - **頭部タッチセンサーのなでなで**（前方/後方スワイプ、または長押し）
  - **画面中央の顔パーツタップ**
- **動作**:
  1. 画面表示が「ARIGATO!」に切り替わり、目を細めてにっこり笑顔になる
  2. 首を大きく 180 度反転させて少し上を見上げる
  3. 丁寧に深くお辞儀をして少し静止
  4. ゆっくりと頭を上げて正面に戻る

## アーキテクチャ・実装詳細

- **アプリ構造**: `mooncake::AppAbility` ベース
- **UI フレームワーク**: LVGL v9
  - UI 操作とバックグラウンドタスク（esp_timer等）の競合を防ぐため `LvglLockGuard` を使用
- **タイマー制御**: `esp_timer` による 1 秒周期のハードウェアタイマー割り込み
  - イベントは FreeRTOS キュー経由でノンブロッキングに受信処理
- **オーディオ合成**:
  - 外部ファイル不要の波形動的生成（正弦波 + 減衰包絡線 + ハーモニクス）
  - 専用の FreeRTOS タスク（`timer_snd`）で非同期再生し、UI やサーボ処理をブロックしない設計
- **モーション制御**: `GetStackChan().motion()` API によるノンブロッキング制御
